# 🎡 SPINKELAS · LUCKY WHEEL

Aplikasi web Lucky Wheel (Roda Putar Undian) responsif khusus layar mobile (HP), pas di layar tanpa keluar atau scroll samping, bersih tanpa keterangan, dan tanpa emoji petir.

---

## 🚀 Cara Menjalankan

### Melalui Script Bash Termux:
```bash
cd ~/spinkelas
./start.sh
```

### Akses di Browser HP:
👉 **`http://localhost:3300`**

## 🌟 Fitur Unggulan

- **Khusus Layar Mobile:** Lebar terpusat maksimal 480px, roda pas di layar HP tanpa memotong tampilan atau keluar layar.
- **Bersih Tanpa Keterangan:** Irisan roda, tabel peserta, riwayat, dan popup pemenang hanya menampilkan nama peserta secara bersih.
- **Bebas Emoji Petir:** Seluruh tombol dan tampilan bersih dari emoji petir.
- **Waktu & Tanggal Realtime:** Jam digital WIB realtime berdetik dan tanggal hari ini di header serta riwayat putaran.
- **Animasi Awal (Intro Splash):** Cincin berputar neon, progress bar halus, dan putaran pemanasan roda 360°.
- **Modal Konfirmasi Berdesain Mewah:** Dialog konfirmasi kustom yang elegan dengan icon badge bercahaya menggantikan popup bawaan browser.
